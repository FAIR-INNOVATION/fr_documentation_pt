Introdução
===================

FRCap é um plugin baseado na web que pode ser integrado ao WebApp do robô colaborativo. O FRCap constrói uma página de configuração ou aplicação para o WebApp do robô colaborativo usando módulos como Element Plus, frcap-ui e frcap-api, baseados em Node.js e Vue3, para estender as funcionalidades e os cenários de aplicação do robô.

Em essência, o FRCap é uma aplicação web que roda em um ambiente Node.js, independente do WebApp, que fornece serviços de gerenciamento e acesso. O FRCap pode interagir com o controlador do robô através das interfaces oficiais fornecidas, ou os clientes podem escrever instruções de interface personalizadas e lógicas de processamento de acordo com as necessidades reais para um desenvolvimento personalizado.
